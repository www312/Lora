# Lora 工程 — 引脚接线说明（EWM22A）

本工程为 **HC-SR04 超声波触发 + EWM22A LoRa 定点发送**。LoRa 参数在模组内已配置；STM32 仅通过串口发送数据帧。

## 一、EWM22A 与 STM32F103（USART3）

| EWM22A 引脚 | 引脚号 | 方向 | 接 STM32 / 电源 |
|-------------|--------|------|-----------------|
| VCC | 14 | 电源入 | **3.3V**（勿用 5V TTL） |
| GND | 1,3,4,13,22,24 | 地 | **GND** |
| RXD | 16 | 串口入 | **PB10**（USART3_TX） |
| TXD | 15 | 串口出 | **PB11**（USART3_RX） |
| AUX | 19 | 出 | **不接**（本工程未使用） |
| WAKE | 8 | 入 | **不接**（未使用深度休眠唤醒） |
| RST | 21 | 入 | **不接**（保持模组内部上拉默认） |
| LINK | 7 | 出 | **不接**（BLE/WiFi 状态，与本工程无关） |
| ANT | 2 | 天线 | 接对应频段 LoRa 天线（400/900MHz 与模组型号一致） |

串口参数（须与模组保存的配置一致）：

- 波特率：**115200**（可在 `Lib/Inc/app_config.h` 中改 `LORA_EWM22A_BAUD`）
- 格式：**8N1**

## 二、HC-SR04 超声波

| HC-SR04 | 接 STM32 / 电源 |
|---------|-----------------|
| VCC | 5V |
| GND | GND |
| Trig | **PA0**（输出） |
| Echo | **PA1**（输入，须分压至 3.3V 安全电平） |

触发距离阈值：`Lib/Inc/app_config.h` → `DIST_THRESHOLD_CM`（默认 20 cm）。

## 三、已移除的 A39 接线（勿再接）

原 A39-T900 的 **M0→PB4、M1→PB3** 已取消，PB3/PB4 可悬空或作他用。

## 四、定点发送帧格式（STM32 组帧）

模组须已设为 **定点传输**（`AT+TRANS=1` 或寄存器 REG3 定点位）。

每次触发发送的 UART 数据为：

```text
[ADDH][ADDL][CHAN] + 遥测正文
```

默认目标（在 `app_config.h` 修改）：

- 地址：`LORA_DST_ADDR` = `0x0003` → 字节 `00 03`
- 信道：`LORA_DST_CHAN` = **与 `AT+CHANNEL` 十进制相同**  
  - 例：两端 `AT+CHANNEL=30` → 写 `30u`，串口第 3 字节为 **`0x1E`**（不是 `0x30`）  
  - **易错**：旧 A39 在 AS_DS 里勾选 HEX 填 30 才对应字节 `0x30`；EWM22A 用 AT 时填 30 就是十进制 30

须与 **接收端 EWM22A** 的本机地址、信道及空中参数一致。

## 五、模组侧建议配置（参考，已在模组内完成可忽略）

发射端建议（示例，以你实际配置为准）：

- `AT+TRANS=1` — 定点
- `AT+HMODE=1` — UART/LoRa 透传（非配置模式 0）
- 本机地址与接收端地址不同
- 波特率 115200，与固件 `LORA_EWM22A_BAUD` 一致

接收端：本机地址 = 发送帧中的目标地址，信道一致，`AT+TRANS=1`。

详细参数见《EWM22A-xxxBWL22S_UserManual_CN_V1.1.pdf》。

## 六、供电与天线

- 模组供电 **3.0～3.6V**，推荐稳定 3.3V，共地。
- LoRa 天线使用模组规定频段（EWM22A-**900** 或 **400**），安装时避免金属遮挡。
